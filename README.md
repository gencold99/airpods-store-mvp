# AirPods Store MVP

Bright Future premium AirPods e-commerce frontend MVP.

## Start

```bash
npm install
npm run dev
```

## Validation

```bash
npm run typecheck
npm run lint
npm test
npm run build
```

The first increment establishes the Next.js app shell, Bright Future design system, domain models, configuration-driven business values, repository interfaces/mock implementations, and core routes. Commercial data, assets, delivery, warranty, and payment values are intentionally placeholders until verified.
